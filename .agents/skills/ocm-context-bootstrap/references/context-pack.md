# Context Pack template

Sections: Task, Domain, Authoritative Sources, Relevant ADRs (full path), Current Decisions,
Requirements, Invariants, Constraints, Relevant Code, Relevant Tests, Research,
Rejected Approaches, Known Failures, Open Questions, Provenance, Authority Classification, Risks.

Each item: one line, a source path (with line range if code) and one status:
CURRENT | HISTORICAL | PROPOSED | REJECTED | UNKNOWN.
Empty section => INSUFFICIENT EVIDENCE.
